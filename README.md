# ledgerlint · 莱哲

> 把银行流水和发票丢进去，出来一份会计一看就懂、能直接复核的凭证包——在交给代账或税局之前，自己先对一遍。

**状态：早期开发中，尚不可用。** v0.1 计划 2026 年 12 月发布。

---

## 这是什么

`ledgerlint` 是一个本地优先的开源工具，面向**没有专职会计的技术型小微企业创始人**。

它做一件事：读你的**银行流水**和**发票台账**，生成一份**凭证草稿包**（凭证清单 + 科目余额表 + 利润表草稿 + 机检报告 + 局限说明），供你自查，或交给代账/会计复核。

## 这不是什么

- **不是代账软件**，不替你做账、不替你申报
- **不是记账 App**，不做个人流水账
- **不是"无人值守全自动做账"**——每一张草稿都要人确认
- **不用大模型生成科目或金额**。科目和金额只能来自确定性规则或人工输入

名字里的 `lint` 是有意的：lint 不修改你的代码，只指出问题。ledgerlint 也不动你的账，只告诉你哪一笔可能记错、依据是什么、以及**它查不出什么**。

## 设计上的三个硬约束

| 约束 | 含义 |
|---|---|
| **本地** | 数据不出本机，不上云、不注册账号 |
| **纯文本** | 账本是一组可 `git diff` 的 JSONL 文件，可备份、可带走、可审计 |
| **带局限** | 每条机检结论都随身携带「本次没查什么」，不允许只给绿勾 |

## 快速开始

尚不可用。当前仓库处于 T01–T04 阶段（工程骨架 + 契约冻结 + journal 存储 + 哈希链）。

## 路线图

- **v0.1（2026-12）**：流水/发票 → 凭证草稿 → 交付包，5 条 BLOCK 级机检
- **v0.2+**：更多银行与支付平台格式、条款引用、Beancount 导出

暂不计划：一般纳税人进项抵扣、直连税局申报、发票真伪查验、多人协作、进销存、移动端、云同步。

## 技术形态（计划）

```bash
npx ledgerlint ./mybook
```

`mybook/` 目录结构：

```
book.json                主体、准则、纳税人身份
opening.json             期初（仅资产负债科目）
journal/YYYY-MM.jsonl    已确认凭证，含 hash / prevHash
drafts/YYYY-MM.jsonl     草稿
sources/*.csv            原始流水与发票
rules.yaml               规则包（版本锁定）
exports/                 交付包
```
